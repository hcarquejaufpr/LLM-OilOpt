# LLM-OilOpt

**Reproducible research on LLM-assisted mathematical formulation for oilfield optimization.**

This repository is being prepared as a companion to an academic study comparing natural-language prompting with a structured SDD/TDD workflow for mathematical optimization models. The research context includes MILP, piecewise-linear (PWL) approximations, SOS2 constraints, and reservoir simulation with the Egg Model / OPM Flow.

## Status

**Initial setup — private working repository.** No validated benchmark datasets, reference formulations, or experimental results have been published here yet. The material in this repository must not be interpreted as a reproduction package for the paper until a documented release is created.

## Planned organization

- [benchmark](benchmark/README.md): problem specifications, authorized input data, and reference formulations.
- [experiments](experiments/README.md): exploratory and controlled evaluations across tools, including Open Math OS.
- [validation](validation/README.md): numerical checks, audit protocols, and reproducibility evidence.
- [docs](docs/README.md): study methodology, publication references, and release documentation.

## Research boundaries

The existing confirmatory experiments and their source records remain in the primary research repository. Exploratory Open Math OS tests must be identified as such and must not be retroactively included in confirmatory comparisons.

Only files checked for provenance, redistribution permissions, confidentiality, and completeness should be copied here. All experimental claims require reproducible evidence.
